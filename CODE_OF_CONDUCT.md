# Code of conduct

wiringmap follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient, and assume good intent. Harassment, insults and
personal attacks are not tolerated, in issues, pull requests or anywhere else the
project is discussed.

If something goes wrong, contact the maintainer, [@Burnaviour](https://github.com/Burnaviour),
through GitHub. Reports are handled privately.
